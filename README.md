# Spectrum Library

Spectrum Library is a lightweight native PlayStation 5 content manager designed to organize and deliver supported game files through a simple, clean, and user-friendly interface. Its streamlined library brings together categories, cover artwork, file details, download controls, and installation status, making it easier to browse available content and manage downloads from one place.
